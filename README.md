# 🚀 Projek 3D Roket Mainan - [Nama] - [NIM]

Proyek ini merupakan implementasi pemodelan objek 3D menggunakan bahasa pemrograman **Python** dan divisualisasikan langsung di browser menggunakan **Plotly** dan **Pyodide**.

---

## 🎯 Deskripsi Model

Objek yang dimodelkan adalah **roket mainan**, dibangun dari **komposisi 3 bentuk dasar 3D**:

- **Silinder**: Digunakan sebagai badan utama roket.
- **Kerucut**: Sebagai kepala roket.
- **Kubus**: Digunakan untuk tiga buah sirip roket.

---

## 🛠 Transformasi yang Diterapkan

Setiap bentuk dasar mengalami minimal dua transformasi:

- **Translasi (pergeseran posisi)**: Misalnya, sirip-sirip roket diposisikan secara simetris di kiri, kanan, dan belakang.
- **Rotasi**: Bentuk dasar bisa dirotasi jika diperlukan (saat ini tidak digunakan, tapi dapat dengan mudah ditambahkan).
- **Skala**: Masing-masing bentuk memiliki ukuran yang disesuaikan untuk membentuk proporsi yang tepat.
